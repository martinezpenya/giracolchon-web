Política de privacitat

Última actualització: 28 de setembre de 2026

En resum: GiraColchón no té comptes, no arreplega dades personals i guarda tot el que introduïxes només al teu mòbil.

Responsable

David Martínez Peña, desenvolupador de l'app. Contacte: contacto@martinezpenya.es.

Dades que guarda l'app

Els matalassos, les seues mides, l'historial de girs, els ajustos i les fotos o documents que adjuntes es guarden en l'emmagatzematge intern del mòbil. No s'envien a cap servidor.

Si tens activada la còpia de seguretat d'Android, el sistema pot incloure estes dades en la còpia del teu compte de Google, segons la configuració del teu telèfon.

Còpies de seguretat

L'app crea còpies en un arxiu ZIP, que pots protegir amb contrasenya. Tu decidixes si el comparteixes i on el guardes (Drive, OneDrive, Nextcloud o un altre servei). El tractament en eixe servei el regix la seua pròpia política.

Anuncis de patrocinadors

Per a mostrar ofertes, l'app descarrega com a molt una vegada al dia un catàleg públic des de giracolchon.martinezpenya.es. La petició no inclou cap identificador teu ni dades dels teus matalassos. Com en qualsevol connexió a internet, el servidor rep l'adreça IP del mòbil.

No hi ha xarxes publicitàries ni perfils. Si obris un anunci, s'obri la web de l'anunciant en el teu navegador, amb la seua pròpia política.

Permisos

  • Notificacions i alarmes exactes: per a avisar-te a l'hora que tries.
  • Inici del dispositiu: per a tornar a programar els avisos després de reiniciar.
  • Internet: només per al catàleg d'anuncis.
  • Fotos i documents: només els que tries tu des del selector del sistema.

Els teus drets

Com que no tractem dades personals, no hi ha res a consultar, corregir ni esborrar en els nostres servidors. Per a esborrar les teues dades, desinstal·la l'app o esborra-les des dels ajustos d'Android. Per a qualsevol dubte, escriu a contacto@martinezpenya.es.

Esta web

Esta web està allotjada en GitHub Pages i l'APK es descarrega des de GitHub Releases. GitHub rep l'adreça IP de qui visita la web o descarrega l'arxiu. No usa galetes, analítiques ni fonts de tercers.

Canvis

Si esta política canvia, es publicarà ací amb una nova data d'actualització.
